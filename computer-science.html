Practice Question Bank

Study practice: These original revision questions are not official board questions. Open each answer to self-check and trace the algorithms by hand.

  1. Compare an array and a linked list for storing a sequence.
    Check answer

    An array stores elements in indexed, usually contiguous locations and supports fast indexed access. A linked list stores nodes connected by links; insertion or deletion at a known node can be efficient, but accessing an element requires traversal.

  2. What are the roles of a primary key and a foreign key in a relational database?
    Check answer

    A primary key uniquely identifies each row in its table. A foreign key refers to a key in another (or the same) table and helps maintain a valid relationship between records.

  3. Describe an algorithm to find the largest value in a non-empty array.
    Check answer

    Set largest to the first element. Scan each remaining element; whenever a value exceeds largest, replace it. Return largest. This takes O(n) time and O(1) extra space.

  4. State two ways to protect personal data online.
    Check answer

    Use unique strong passwords (preferably with a password manager) and enable multi-factor authentication. Also avoid sharing sensitive data on untrusted sites and keep software updated.

  5. How does a client-server request usually work?
    Check answer

    A client sends a request over a network to a server. The server processes it and returns a response; the client then displays or uses that response.

  6. When can binary search be used, and what is its time complexity?
    Check answer

    It requires data ordered by the search key. Each comparison halves the remaining search interval, so its time complexity is O(log n).

  7. Write an SQL query to show the names of students whose marks are at least 60 in a table named Students.
    Check answer

    SELECT name FROM Students WHERE marks >= 60;

  8. What is the difference between syntax and a logic error?
    Check answer

    A syntax error violates the language's grammar and is usually caught before execution. A logic error allows the program to run but produces an incorrect result.
