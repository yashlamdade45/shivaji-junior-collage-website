Original Mathematics Practice

Study practice: These questions are original practice prompts, not official board questions. Show the method as well as the final result.

  1. Differentiate f(x) = x³ − 4x + 2.
    Check answer

    Using the power rule, f′(x) = 3x² − 4.

  2. Evaluate ∫(2x + 3) dx.
    Check answer

    x² + 3x + C, where C is an arbitrary constant.

  3. Find the determinant of [[2, 1], [3, 4]].
    Check answer

    For [[a, b], [c, d]], determinant = ad − bc. Here it is 2 × 4 − 1 × 3 = 5.

  4. A fair six-sided die is rolled. What is the probability of getting an even number?
    Check answer

    There are three favourable outcomes (2, 4, 6) among six equally likely outcomes, so the probability is 3/6 = 1/2.

  5. Find the sum of the first five terms of the arithmetic progression 3, 7, 11, ...
    Check answer

    The first five terms are 3, 7, 11, 15, 19. Their sum is 55.

  6. Solve the simultaneous equations x + y = 7 and x − y = 1.
    Check answer

    Adding the equations gives 2x = 8, so x = 4; then y = 3.

  7. Find the dot product of vectors (1, 2) and (3, 4).
    Check answer

    (1 × 3) + (2 × 4) = 11.

  8. Evaluate lim x→2 (x² − 4)/(x − 2).
    Check answer

    Factor the numerator: (x − 2)(x + 2). For x ≠ 2 the expression simplifies to x + 2, so the limit is 4.
